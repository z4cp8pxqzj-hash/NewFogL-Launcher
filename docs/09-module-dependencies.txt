文档版本：1.1.0

================================================================================
第一部分  依赖规则
================================================================================

--------------------------------------------------------------------------------
1.1  依赖方向
--------------------------------------------------------------------------------

	依赖只允许单向，不允许循环。

	允许：
		A → B → C

	禁止：
		A → B → A

	禁止：
		A → B → C → A


--------------------------------------------------------------------------------
1.2  层次划分
--------------------------------------------------------------------------------

	加载器（Java 侧）：
		第1层：model（数据模型，被所有层依赖）
		第2层：log（日志，被所有层依赖）
		第3层：scanner（扫描器，依赖 model + log）
		第4层：preflight（预检，依赖 model + log + scanner）
		第5层：resolver（解析，依赖 model + log + preflight）
		第6层：deploy（部署，依赖 model + log + resolver）
		第7层：sandbox（沙盒，依赖 model + log + resolver）
		第8层：launcher（启动，依赖 model + log + 以上全部）
		第9层：Main（入口，依赖所有层）

	启动器（C++ 侧）：
		第1层：core（基础，无依赖）
		第2层：fs（文件，依赖 core）
		第3层：process（进程，依赖 core）
		第4层：ipc（通信，依赖 core + process）
		第5层：guardian（守护，依赖 core + process）
		第6层：resource（资源，依赖 core + fs）
		第7层：instance（实例，依赖 core + fs）
		第8层：pack（导出导入，依赖 core + fs）
		第9层：app（启动流程编排，依赖 core + process + ipc + instance）
		第10层：ui（界面，依赖所有前置层 + app）
		第11层：main.cpp（入口）

第四部分  禁止的依赖方向
================================================================================

--------------------------------------------------------------------------------
4.1  禁止示例
--------------------------------------------------------------------------------

	禁止1：model 依赖 scanner
		· model 是最底层，不允许依赖任何业务模块

	禁止2：log 依赖 model
		· log 只依赖 JDK，不依赖项目内其他类

	禁止3：scanner 依赖 preflight
		· scanner 不知道 preflight 存在
		· 数据流向是 scanner → preflight，反向禁止

	禁止4：deploy 依赖 sandbox
		· deploy 和 sandbox 平级，互不依赖

	禁止5：core 依赖 fs
		· core 是启动器的最底层，不依赖任何业务模块

	禁止6：ui 绕过 app 直接调用 process/ipc 的业务细节
		· ui 只通过 app 层（LaunchFlow）间接触达底层流程


--------------------------------------------------------------------------------
4.2  检查方法
--------------------------------------------------------------------------------

	写完一个模块后，检查：

		1. import 语句里是否只有同层或更低层的包
		2. 是否有反向依赖

	如果发现反向依赖 → 打回重写，不允许"通过反射绕过"。

--------------------------------------------------------------------------------

	Main.main()

	ForgeParser.parse()
	NeoForgeParser.parse()
		↓ 返回
		↓
	PreFlightChecker.check()
		↓ 内部依次调用
	MultiVersionChecker.check()
	CrossLoaderChecker.check()
	DependencyChecker.check()
	SkinModChecker.check()
	DuplicateChecker.check()
		↓
	TopologicalSorter.sort()
		↓ 内部调用
	DependencyGraph.addNode/addEdge()
	TarjanSCC.findSCC()
		↓
	CycleGroupResolver.resolve()
		↓
	LoaderPrioritySorter.sort()
		↓
	FingerprintGenerator.generate()
		↓
	CacheValidator.validate()
		↓
	ModDeployer.deploy()
		↓ 内部调用
	FileLinker.createLink()
	DeployManifestWriter.write()
		↓
	SandboxPlanner.plan()
		↓
	ScriptGenerator.generate()
		↓
	GameProcessLauncher.launch()
		↓
	System.exit(exitCode)
