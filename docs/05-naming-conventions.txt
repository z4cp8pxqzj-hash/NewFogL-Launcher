================================================================================
NewFogL 补充文档 2 —— 命名规范
================================================================================

文档版本：1.1.0
适用范围：C++ 启动器 + Java 加载器
目的：统一类名、方法名、变量名、常量、文件名、目录名的命名


================================================================================
第一部分  Java 侧命名
================================================================================

--------------------------------------------------------------------------------
1.1  包名
--------------------------------------------------------------------------------

	格式：全小写，点分隔

	根包：com.newfogl.loader

	子包：
		com.newfogl.loader.model		数据模型
		com.newfogl.loader.scanner		扫描器
		com.newfogl.loader.preflight	静态预检
		com.newfogl.loader.resolver		依赖解析
		com.newfogl.loader.deploy		部署
		com.newfogl.loader.sandbox		沙盒规划
		com.newfogl.loader.launcher		启动脚本与游戏进程
		com.newfogl.loader.log			日志


--------------------------------------------------------------------------------
1.2  类名
--------------------------------------------------------------------------------

	格式：大驼峰（UpperCamelCase）

	普通类：
		ModDescriptor
		MetadataScanner
		PreFlightChecker
		FatalArbitrationError

	枚举：
		LoaderTag
		LogLevel
		CrashType

	接口：
		（本项目暂不使用接口，全部用具体类）

	抽象类：
		（本项目暂不使用抽象类）

	工具类：
		（本项目不设独立工具类，按职责分到模块里）


--------------------------------------------------------------------------------
1.3  方法名
--------------------------------------------------------------------------------

	格式：小驼峰（lowerCamelCase）

	动词开头：
		scan()
		detect()
		check()
		parse()
		deploy()
		resolve()
		generate()
		validate()

	判断型：
		isValid()
		hasConflict()
		exists()
		shouldSkip()

	获取型：
		getShortId()
		getLoaderType()

	设置型：
		setShortId()
		setLoaderType()

	构建型：
		buildGraph()
		createSandbox()

	禁止：
		· 单字母方法名
		· 拼音方法名
		· 缩写（除了 getShortId 这种公认缩写）


--------------------------------------------------------------------------------
1.4  变量名
--------------------------------------------------------------------------------

	格式：小驼峰

	普通变量：
		modsDir
		cacheDir
		versionsDir
		shortId
		loaderType
		modCount

	循环变量：
		常规用 i / j / k，嵌套不超过 3 层
		遍历集合用有意义的单数名：
			for (ModDescriptor mod : mods) { ... }

	临时变量：
		可以用 tmp，但作用域不超过 5 行
		超过 5 行的临时变量起有意义的名字

	禁止：
		· 单字母变量（除了循环变量 i/j/k）
		· 拼音变量名
		· 无意义缩写（如 md 代替 modDescriptor）


--------------------------------------------------------------------------------
1.5  常量名
--------------------------------------------------------------------------------

	格式：全大写下划线（UPPER_SNAKE_CASE）

	示例：
		GAME_VERSION = "1.20.1"
		FORGE_VERSION = "47.4.26"
		LOG_MAX_SIZE = 10 * 1024 * 1024
		JAVA_VERSION_LOADER = 21

	要求：
		· 所有魔法数字必须提取为常量
		· 常量集中放在 Constants.java 里
		· 常量名要能说明它是什么


--------------------------------------------------------------------------------
1.6  枚举值
--------------------------------------------------------------------------------

	格式：全大写

	示例：
		LoaderTag.FORGE
		LoaderTag.NEOFORGE
		LoaderTag.FABRIC
		LoaderTag.UNKNOWN

		LogLevel.DEBUG
		LogLevel.INFO
		LogLevel.WARN
		LogLevel.ERROR
		LogLevel.FATAL


--------------------------------------------------------------------------------
1.7  文件名
--------------------------------------------------------------------------------

	与类名一致，一个文件一个类

	示例：
		LoaderTag.java
		ModDescriptor.java
		MetadataScanner.java
		PreFlightChecker.java

	禁止：
		· 一个文件多个类（内部类除外）
		· 文件名与类名不一致
		· 文件名全小写


================================================================================
第二部分  C++ 侧命名
================================================================================

--------------------------------------------------------------------------------
2.1  命名空间
--------------------------------------------------------------------------------

	统一使用：

		namespace NewFogL {
			...
		}

	子模块不设独立命名空间。


--------------------------------------------------------------------------------
2.2  类名
--------------------------------------------------------------------------------

	格式：大驼峰

	示例：
		Junction
		FileLock
		ProcessLauncher
		CrashDetector
		PackExporter
		StateParser
		ResourceExtractor
		JunctionSync


--------------------------------------------------------------------------------
2.3  方法名
--------------------------------------------------------------------------------

	格式：小驼峰

	示例：
		createJunction()
		isJunction()
		extractLauncherResources()
		launchLoader()

	判断型：
		isFileLocked()
		hasJavaProcess()

	获取型：
		getExeDir()
		getMcDir()
		getPid()


--------------------------------------------------------------------------------
2.4  成员变量
--------------------------------------------------------------------------------

	格式：小驼峰 + 尾部下划线

	示例：
		class ProcessMonitor {
		private:
			DWORD pid_;
			std::atomic<bool> running_;
			HANDLE hReadPipe_;
		};

	局部变量不加下划线：

		void foo() {
			std::string exeDir = getExeDir();
			HANDLE processHandle = ...;
		}


--------------------------------------------------------------------------------
2.5  常量
--------------------------------------------------------------------------------

	格式：k 前缀 + 大驼峰

	示例：
		constexpr int kJavaVersionLoader = 21;
		constexpr int kJavaVersionGame = 17;
		constexpr const char* kGameVersion = "1.20.1";
		constexpr size_t kLogMaxSize = 10 * 1024 * 1024;

	或者使用全大写下划线（与 Java 一致）：

		constexpr int JAVA_VERSION_LOADER = 21;

	本项目推荐用 k 前缀风格。


--------------------------------------------------------------------------------
2.6  文件名
--------------------------------------------------------------------------------

	头文件：类名.h
	源文件：类名.cpp

	示例：
		Junction.h / Junction.cpp
		FileLock.h / FileLock.cpp
		ProcessLauncher.h / ProcessLauncher.cpp

	禁止：
		· 文件名全小写
		· 文件名加前缀后缀（如新加 _impl / _util）


--------------------------------------------------------------------------------
2.7  Qt UI 自绘组件命名约定
--------------------------------------------------------------------------------

	适用范围：src/ui/ 目录下的所有界面类。

	自绘组件：统用 NF 前缀 + 大驼峰

		NFButton			自绘按钮
		NFListWidget		自绘列表及列表项
		NFSwitch			自绘滑动开关
		NFDialog			自绘通用弹窗

	无边框窗口基类：

		FramelessWindow		不带 NF 前缀，作为窗口基类单独命名

	页面类：统一 Page 后缀

		VersionSelectPage		版本选择页面
		InstanceSettingsPage	实例设置页面

	布局容器（非 Page）：

		Sidebar				左侧边栏
		LogPanel			右侧日志输出面板

	要求：
		· 自绘组件（NF 前缀）只负责外观与交互，不承载业务逻辑
		· Page 后缀只用于内容区整页，局部面板用 Sidebar / LogPanel 这类职能名
		· 其余命名禁止项不变（见 2.6）

第四部分  项目文件命名
================================================================================

--------------------------------------------------------------------------------
4.1  配置文件
--------------------------------------------------------------------------------

	格式：kebab-case（短横线分隔）

	示例：
		NewFogL-config.json
		instance-template.json
		pack-manifest-template.json
		newfog-rules.json
		newfog-fingerprint.sha256
		deploy-manifest.json
		zh-CN.json


--------------------------------------------------------------------------------
4.2  脚本文件
--------------------------------------------------------------------------------

	格式：kebab-case

	示例：
		工业时代.bat
		纯净生存.bat
		start-forge.bat

	实例名可以包含中文，但文件名本身用连字符分隔关键词。


================================================================================
第五部分  禁止的命名
================================================================================

--------------------------------------------------------------------------------
5.1  通用禁止
--------------------------------------------------------------------------------

	· 拼音命名（如 mokuai / jiazai）
	· 无意义缩写（如 mdesc / pcheck）
	· 单字母名（除循环变量 i/j/k）
	· 数字后缀（如 mod1 / mod2）
	· 类型前缀（如 strName / intCount，Java 里不需要）
	· 临时命名（如 test / tmp / abc）


--------------------------------------------------------------------------------
5.2  容易踩坑的场景
--------------------------------------------------------------------------------

	场景1：枚举值用字符串
		反例：LoaderTag.FORGE = "F"
		正例：LoaderTag.FORGE

	场景2：方法名包含返回类型
		反例：getStringName()
		正例：getName()

	场景3：布尔变量用否定
		反例：isNotReady
		正例：isReady（使用时用 !isReady）

	场景4：常量混在类里
		反例：class LoaderDetector {
				  private static final int MAX_COUNT = 100;
			  }
		正例：常量统一放到 Constants.java

第六部分  命名检查清单
================================================================================

	□ 包名全小写
	□ 类名大驼峰
	□ 方法名小驼峰，动词开头
	□ 变量名小驼峰，有意义
	□ 常量全大写或 k 前缀
	□ 枚举值全大写
	□ 文件名与类名一致
	□ 没有拼音
	□ 没有无意义缩写
	□ 没有单字母（除循环变量）
	□ 配置文件 kebab-case
	□ 没有类型前缀
