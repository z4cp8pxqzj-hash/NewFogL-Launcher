2.4  字段说明
--------------------------------------------------------------------------------

	字段						类型		必填	说明
	------------------------	--------	----	----------------------------
	version						string		是		配置版本号
	accounts					array		是		账号列表，未登录时为空数组
	accounts[].id				string		是		账号唯一标识
	accounts[].type				string		是		固定 microsoft（仅支持正版登录）
	accounts[].username			string		是		玩家名
	accounts[].uuid				string		是		玩家 UUID
	accounts[].accessToken		string		否		正版登录令牌
	accounts[].refreshToken		string		否		正版刷新令牌
	accounts[].expiresAt		string		否		令牌过期时间
	accounts[].isDefault		bool		是		是否默认账号
	java.jre17Path				string		是		jre-17 可执行文件路径
	java.jre21Path				string		是		jre-21 可执行文件路径
	java.defaultVersion			int			是		默认 Java 版本
	ui.language					string		是		语言（固定 zh-CN）
	ui.theme					string		是		主题（dark / light）
	ui.windowWidth				int			是		窗口宽度
	ui.windowHeight				int			是		窗口高度
	download.mirror				string		是		下载镜像源
	download.maxThreads			int			是		最大下载线程数
	logging.debugEnabled		bool		是		DEBUG 是否输出
	logging.consoleFilter		array		是		控制台输出的模块白名单

	javaErrorPrompt.showModJavaMismatch	bool		是		是否提示模组 Java 不匹配

	lastLaunched						string		是		上次启动时间
	lastResult							string		是		success / crash

--------------------------------------------------------------------------------
4.4  字段说明
--------------------------------------------------------------------------------

	字段						类型		说明
	------------------------	--------	----------------------------
	instanceName				string		实例名

	loadOrder					array		模组加载顺序
	cycleGroups					array		环组列表

	说明：loader / loaderVersion 当前由加载器固定写为 "mixed"；
	各加载器实际归属见 sandboxes[].loader。

第九部分  配置文件版本兼容
================================================================================

--------------------------------------------------------------------------------
9.1  版本号规则
--------------------------------------------------------------------------------

	格式：{主版本}.{次版本}.{修订版本}

	· 主版本变更 → 不兼容
	· 次版本变更 → 向下兼容
	· 修订版本变更 → 忽略


--------------------------------------------------------------------------------
9.2  不兼容变更的处理
--------------------------------------------------------------------------------

	启动器读取配置时，检查 version 字段：

		if (config.version.startsWith("0.")) {
			// 旧版本，执行迁移
			migrate(config);
		} else if (!config.version.startsWith("1.")) {
			// 太新的版本，拒绝加载
			throw new ConfigVersionException("配置版本过新");
		}


	当前实现（Config::loadGlobal）：version 不以 "1." 开头时，记 WARN 并直接
	返回默认配置，不做旧版本迁移，也未抛出异常（上文伪代码为设计意图）。


--------------------------------------------------------------------------------
9.3  字段缺失的处理
--------------------------------------------------------------------------------

	读取配置时，缺失的字段用默认值补全：

		config.ui.language = json.getOrDefault("language", "zh-CN");
		config.logging.debugEnabled = json.getOrDefault("debugEnabled", true);

	不因为字段缺失而抛异常。
